Set up a brand-new robot

A robot straight out of the box knows no WiFi. It makes its own network called reachy-mini-ap and waits. This does the whole handover: joins that network, asks the robot which WiFi it can see, hands over your password, then puts this laptop back where it was.

Your internet will drop for a minute or two while this laptop is on the robot’s network. That is normal. This page keeps working the whole time — it runs on your own machine.
Bluetooth works even when the robot has no WiFi at all, so this finds robots that nothing else can see.

Name this robot

Why this matters. Every Reachy Mini leaves the factory advertising itself as reachy-mini.local — the same name on every unit. With one robot that is fine. With two on the same network, the name still resolves, but you cannot predict which robot answers. A demo where the wrong robot nods is worse than one that crashes. Giving each a distinct name makes it deterministic.
Lowercase letters, digits and hyphens. Suggestion: reachy-mini-a for the first robot, -b for the second, -c for the third.
The new name takes effect after a reboot. Renaming goes in over SSH — there is no API for it.

When you want the official app

Once your robots are set up, named, and showing green here, the official Reachy Mini Control app does several things this dashboard does not:

  • Camera preview — live video from the robot’s eye
  • Speaker and microphone — volume, test sounds, listening
  • Hugging Face sign-in — needed to install or update apps
  • System updates — the robot’s own software
It cannot find the robot on this network — it looks only for reachy-mini.local, and campus WiFi blocks the mDNS that depends on. So copy the address below, open the app, and paste it into “Connect by IP address…”. You have to paste it every time; the app does not remember it.

Prove it works

Motors are the usual gotcha. With them off, the robot accepts every movement command, returns success, and does nothing at all. “Wake up” switches them on. If nothing moves, check the Motors reading on the Diagnostics tab first.
“Let go” switches the motors off so you can move the head by hand — do that before packing it away.
Nothing working? Read this first
  • Is the robot powered on? Press OFF, wait 5 seconds, press ON, then wait a full 2 minutes before searching again.
  • Brand-new robot? Use Step 1 on the Setup tab. It has no WiFi yet and nothing but Bluetooth can see it.
  • Reachy can only join normal password networks. It cannot join AirOrangeX or eduroam — those need enterprise logins the robot has no way to complete. Use ISCHOOL_IOT or a phone hotspot.
  • Found it but it will not move? The motors are off. Press “Wake up” on the Motion tab.
  • Bluetooth search failing? Close Reachy Mini Control — it holds the Bluetooth radio and blocks this dashboard from using it.
  • Two robots on at once and the wrong one responds? They share the factory name. Rename them on the Setup tab.
