How it’s doing

Test that it works

If the robot moves, everything is working. “Let go” switches the motors off so you can move the head by hand — do that before packing it away.
Nothing happening? Read this first
  • Is the robot powered on? Press OFF, wait 5 seconds, press ON. Give it about 2 minutes to boot before searching again.
  • Is it on the same Wi‑Fi as this laptop? Reachy can only join normal password networks (WPA2). It cannot join AirOrangeX or eduroam. On a new network you have to set it up over Bluetooth first.
  • Robot found but it won’t move? The motors are probably off. Press “Wake up” — that switches them on. Commands are silently ignored while the motors are disabled.
  • Nowhere to connect at all? The robot can make its own Wi‑Fi network. Trigger it over Bluetooth, then join reachy‑mini‑ap from this laptop. That works anywhere, with no router involved.
  • Still stuck? Close the Reachy Mini Control app if it’s open — it holds the Bluetooth radio and blocks this dashboard from using it.
